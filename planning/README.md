# Planning cho web app RAG

Đây là tài liệu planning cho web app có tính năng chính là RAG.

Mục tiêu của app là giúp người dùng tìm kiếm và hỏi đáp trên một bộ tài liệu lớn, gồm nhiều loại file như PDF, Word, Excel, PowerPoint, tài liệu scan,...

Các file trong thư mục:

- `features-pain-points-edge-cases.md`: Danh sách feature, pain point và edge case.
- `solution-directions.md`: Một số hướng giải quyết.
- `workflow.md`: Workflow hoạt động của hệ thống.
